## 翼龙面板到底是什么，为什么“搭建”有两个意思

Pterodactyl 是开源的游戏服务器管理面板，本身不提供游戏算力，它负责启动、停止、查看日志、传文件、分配端口这些操作。自己装一套，官方要求你有一台带 root 的 Linux 服务器（官方支持 Ubuntu 和 Debian），然后建 MariaDB 数据库、用 Redis 做缓存和队列、配置队列进程、装 wings 到每个节点、再配 Web 服务器和 SSL。

官方文档里有一句话写得很直接：这个面板“不是一个拖拽即用的服务”，如果你不打算理解基本的 Linux 系统管理，最好现在就掉头。所以自建这条路适合已经会装 MCSM、会配 Nginx 反代的人，不适合把开服当目的的新手。

托管形态把这些全包了。雨云的面板服买完以后，用户拿到的只是一个面板账号密码，装面板、配数据库这些步骤根本不存在。需要说明一点：2022 年那篇雨云官方社区的教程里，这个入口叫“进入翼龙面板”；面板现在具体叫什么、入口按钮在哪，以你后台当前显示为准，教程里的按钮路径可能已经改版。

4. 点 `立即购买`，完成服务器创建。
5. 返回游戏云主页，进入刚创建的实例，在实例页找到“面板账号密码”。

## 三个新手必踩的坑

**地址和端口要拆开填。** 面板上显示的地址是 `地址:端口` 的形式。填进游戏客户端时，冒号前的内容填到“服务器地址”，冒号后的内容填到“端口”，两栏分开。很多人直接把整串粘进地址栏，然后连不上，问题就出在这。在客户端 `服务器` 页面划到最底部，点 `添加服务器`，把两栏分别填好即可。

**面板账号密码不在邮箱里。** 登录翼龙面板用的账号密码，显示在雨云游戏云实例页，不是你的雨云登录密码，也不是游戏账号。第一次进面板找不到密码，先回实例页看，别在登录框反复试。

**换存档要先清空 `worlds`。** 想换成自己的存档，在面板点 `文件`，下滑找到 `worlds` 文件夹，把这个路径下的文件全部删干净，再上传自己的存档进去，然后重启服务器。不删旧文件直接上传，新世界往往不生效，服务器还是跑原来的地图。

## 常见问题

**能在面板服上开 Java 版吗？** 上面那套八步是基岩版（官方基岩版）的流程。Java 版要选对应的游戏类型，或者走 VPS 自己装服务端，具体支持哪些版本以购买页可选类型为准。

**面板密码忘了怎么办？** 账号密码在雨云实例页能看到，先去那里找。实例页没有重置入口的话，联系客服确认，别在面板登录页乱试。

**和朋友联机需要公网 IP 吗？** 面板服走的是托管面板分配的地址和端口，把 `地址:端口` 拆开填进客户端就能连，朋友用同一个地址。要对外开公共服、需要独立公网 IP 的，回到上一节，那是 VPS 的场景。
